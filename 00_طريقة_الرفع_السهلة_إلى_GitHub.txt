طريقة الرفع الأسهل إلى GitHub — بدون إنشاء أي مجلد يدويًا

هذه الحزمة هي Clean Base v2 الأصلية، وبداخلها كل المجلدات والملفات جاهزة.

الطريقة الموصى بها:
1) فك ضغط الملف ZIP على جهازك.
2) افتح GitHub Desktop.
3) Clone للمستودع الذي تريد رفع التطبيق عليه (مثل app22).
4) افتح مجلد المستودع المحلي من GitHub Desktop: Repository > Show in Explorer.
5) احذف محتويات المستودع القديمة (ما عدا مجلد .git المخفي إن ظهر؛ والأفضل لا تلمسه).
6) انسخ كل محتويات هذا المجلد إلى داخل مجلد المستودع المحلي دفعة واحدة. ويندوز سينسخ كل المجلدات المتداخلة تلقائيًا.
7) ارجع إلى GitHub Desktop: ستظهر كل التغييرات.
8) اكتب Commit message مثل: Restore Athar Clean Base v2
9) Commit to main ثم Push origin.

مهم:
- لا ترفع الملفات من صفحة GitHub بالمتصفح ملفًا ملفًا.
- لا ترفع ملف ZIP وحده داخل المستودع؛ GitHub لن يفكّه تلقائيًا ليصبح تطبيقًا.
- هذه الحزمة تحتوي على 58 ملف مشروع أصليًا قبل ملف التعليمات هذا.
- بعد الرفع تأكد أن src/main.tsx وsrc/App.tsx وsrc/data وsrc/components موجودة.
