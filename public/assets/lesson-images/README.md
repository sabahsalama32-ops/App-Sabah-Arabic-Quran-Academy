# صور الدروس

ضع هنا الصور المحلية الخاصة بالتلخيصات والخرائط أو أغلفة المواد عند الحاجة.

يفضل استخدام أسماء واضحة وثابتة، مثل:

- `lesson-01-summary.webp`
- `subject-cover.webp`

ثم استخدم المسار داخل ملفات البيانات بصيغة:

`/assets/lesson-images/lesson-01-summary.webp`

لا تضع صورًا قديمة من تطبيق آخر داخل النسخة الجديدة.
